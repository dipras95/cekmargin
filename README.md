# CekMargin — Toolkit Seller Indonesia

Kalkulator gratis untuk seller Shopee, Tokopedia, dan TikTok Shop: hitung harga jual, batas diskon yang masih untung, dan profit setelah biaya iklan — **sebelum** ikut promo atau pasang iklan. Banyak seller merasa omzet besar tapi uang tidak terkumpul; biasanya karena komisi marketplace, diskon, packing, dan iklan tidak dihitung sejak awal.

**🔗 Situs:** [cekmargin.pages.dev](https://cekmargin.pages.dev)

## Kalkulator

| | |
|---|---|
| [Harga Jual](https://cekmargin.pages.dev/kalkulator-harga-jual) | Dari modal, komisi marketplace, biaya packing, dan target untung → harga jual yang aman |
| [Diskon Aman](https://cekmargin.pages.dev/kalkulator-diskon-aman) | Uji diskon promo: masih untung atau tidak, dan berapa batas diskon maksimum |
| [Iklan vs Profit](https://cekmargin.pages.dev/kalkulator-iklan-profit) | Berapa biaya iklan per pesanan/produk yang masih menyisakan untung bersih |

Ditambah [panduan singkat](https://cekmargin.pages.dev/artikel) (cara hitung harga jual Shopee, diskon tanpa rugi, profit setelah iklan) dan template Excel/Google Sheets profit per produk.

## Stack

Astro 5 (static) · React 19 untuk komponen kalkulator · Tailwind CSS 4 · deploy di Cloudflare Pages

## Menjalankan

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # hasil di dist/
```
